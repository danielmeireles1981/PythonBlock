O que é uma .venv?

É uma caixa de ferramentas separada para cada projeto. As bibliotecas de um projeto não se misturam com as de outro.

Se python não for reconhecido, reabra o terminal após instalar e tente py -3.12 no lugar de python.

    Seu esforço vira XP ✧

    • Setup: 10 XP por item, uma única vez.
    • Laboratório: 50, 75, 100, 150 e 200 XP, respectivamente. Cada desafio recompensa uma vez.
    • Revelar solução: −30 XP imediatamente, sem ficar abaixo de zero. A recompensa daquele desafio passa a 25% (12,5 / 18,75 / 25 / 37,5 / 50 XP).
    • A penalidade é aplicada uma vez por desafio. Reabrir a mesma solução é grátis. Revelar após concluir não altera a recompensa já recebida, mas desconta os 30 XP.
    • Quizzes: 40 XP na primeira tentativa; 20 XP após erro.
    • Calculadora: 15 XP na primeira expressão aritmética válida.
    • Repetir, recarregar ou desmarcar e marcar um item não acumula pontos extras.
